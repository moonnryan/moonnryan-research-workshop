# Qwen3-VL 层次化 SFT 的策略与边界

Qwen3-VL 的领域微调同时改变输出习惯、任务判断和视觉适配。把这些目标一次交给全参数训练，容易让小规模领域数据影响原有能力；分阶段冻结与解冻提供了一种控制更新范围的方式，但阶段越多并不自动意味着效果更好。

这里讨论的层次化 SFT 使用教师生成并经复核的回答作为监督。虽然数据来自大模型，它仍是回答级监督；只有真正使用特征、概率分布或 logits 并定义对应损失，才构成这些层次上的蒸馏。

# 一、三个阶段的作用

| 阶段 | 更新范围 | 主要目标 | 验收内容 |
| --- | --- | --- | --- |
| 格式与指令 | 冻结视觉塔，更新语言端部分层 | 学会任务字段和回答格式 | JSON 与指令遵循 |
| 领域适配 | 扩大语言更新范围，解冻视觉末段 | 学习领域视觉与判定 | 分场景正负样本 |
| 鲁棒性巩固 | 视验证结果扩大范围，小学习率 | 难例与跨场景稳定性 | 独立测试与通用能力 |

原始 Qwen3-VL-2B 方案使用语言端后 10 层和视觉末 4 层等具体划分。层号属于该模型配置，迁移到其他规模时应按实际模块结构检查，不能把数字当通用规则。

# 二、从配置到真实梯度

配置中的“freeze”必须通过参数统计和梯度检查确认。LoRA 目标、全参数更新和自定义冻结逻辑可能叠加，使实际训练范围与设计不同。

```python
trainable = [(n, p) for n, p in model.named_parameters() if p.requires_grad]
print("trainable params:", sum(p.numel() for _, p in trainable))

loss.backward()
updated = [n for n, p in trainable if p.grad is not None]
print("parameters with gradients:", len(updated))
```

视觉适配还需确认 batch 中确实有有效媒体张量。模板选错或路径失效时，训练可能只学习文本标签规律，loss 仍然能够下降。先用小批真实样本检查输入与梯度，比直接启动全量训练更可靠。

# 三、训练下降与效果提升

归档三阶段训练 loss 持续下降，但这个现象不能单独证明阶段策略优于一次训练。阶段切换可能改变数据分布、更新范围和有效 token，loss 也不宜跨阶段直接解释为相同尺度的能力提升。

| 评测项 | 应观察的内容 |
| --- | --- |
| 格式正确率 | 可解析、字段齐全、类型合法 |
| 任务判断 | 每场景准确率、正例召回、负例误报 |
| 难例 | 遮挡、小目标、边界条件 |
| 泛化 | 新来源、未见视频、不同问法 |
| 通用能力 | 未参与领域训练的基本任务 |

当训练 loss 下降而验证错误集中在相同模式，应先检查标注和训练分布。进一步解冻可能强化已有偏差。阶段数、学习率和训练轮次都应由验证集决定，而非必须完成预先写好的三段流程。

# 四、一些反思

分阶段训练的价值是让一次更新更容易解释。若第一阶段改善格式、第二阶段改善视觉判断，可以据此定位收益；若每阶段同时换数据、模板和参数，就失去了这种可解释性。

更好的基线包括同预算的单阶段 LoRA、冻结视觉的语言端微调和分阶段方案。没有这些对照，适合把三阶段写成已执行策略，而不是已证明最优的方法。训练流程中的设计意图与实验结论，应分别保存。
