# Qwen 小模型的结构化输出与任务评测

小规模视觉语言模型用于复判时，输出不仅要符合 JSON 格式，还要给出正确任务判断。格式约束提高可解析性，却不能保证结论正确；领域微调也可能让模型面对通用问题时仍强制输出任务 JSON。

归档 2B 模型在指定评测中达到 JSON 解析率 100%、判断准确率约 88%。两个指标分开报告，并说明来自有限任务集，不代表所有输入的能力。

# 一、输出契约与训练目标

```json
{"hit":false,"summary":"未观察到满足规则的目标"}
```

任务定义要明确正负条件、信息不足时的回答和可观察证据。标注与规则保持一致，同一输入不能用相互矛盾的规则生成目标。

回答级 SFT 优化目标序列的条件概率：

$$
\mathcal{L}_{\mathrm{SFT}}
=-\sum_{t\in\mathrm{answer}}\log p_\theta(y_t\mid x,y_{<t})
$$

字段模板只占任务一部分。判断集中在少量 token，整体 loss 容易掩盖正负样本错误。

# 二、训练与推理解耦

| 层次 | 作用 | 局限 |
| --- | --- | --- |
| 训练 JSON 模板 | 学习字段与语言习惯 | 可能影响其他回答方式 |
| 推理 schema/grammar | 限制可生成结构 | 无法保证判断符合图像 |
| 输出校验 | 检测缺字段、错类型 | 只验证格式 |
| 任务评测 | 检查判断与证据 | 需要独立样本 |

为专用服务约束格式是合理选择；若同模型还承担聊天，通过任务模板或路由明确用途，并测试非领域输入。单一强格式训练不能自动保证所有用途的效果。

# 三、评测应包含失败分布

解析失败、字段非法、结论错误和解释不一致分别统计。按场景报告正例召回、负例误报，保留小目标、遮挡、跨帧与边界难例。

有限样本中的 100% 可能来自样本少或分布简单，总体 88% 也可能隐藏某类任务的错误。发布需要样本量、拆分方式和固定推理设置；缺少这些材料时，数字仅作为归档实验观察。

# 四、字段正确与证据一致

对 JSON 的校验分三层：语法可解析、字段类型符合 schema、字段与画面证据一致。前两层可以用程序严格检查，第三层仍依赖任务标签和人工复核。

例如 hit 为 false 而 summary 描述了明确正例，属于内部不一致；hit 正确但说明指向无关区域，也不应记作解释通过。任务错误最好保留原始图像、prompt 与回答，并按错误类型分组。

正负比例也会影响结果。数据做成 1:1 时的准确率不能直接解释为真实部署误报率；需要以实际分布或独立负例集测量。模型约束和业务阈值应根据这类指标调整，而不是只追求 JSON 解析率。

# 五、一些反思

缩短回答可以降低生成成本，过度压缩却会失去复核证据。专用服务适合保留最少且可观察的判断依据。

训练和约束解码解决不同问题。分别验收格式与视觉判断，才能知道下一轮需要修数据、任务定义还是接口。
